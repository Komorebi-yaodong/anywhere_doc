# 历史对话 💬(Chat History) 使用说明文档

**文档更新时间：2026年6月23日**

欢迎使用 **Anywhere Desktop** 的历史对话功能。本模块用于统一管理、备份、项目化归档与恢复与 AI 的桌面端对话记录。无论是日常聊天、快捷助手多轮会话，还是定时任务自动生成的执行结果，都可以在这里集中查看。

桌面端延续了本地优先的数据策略，并支持通过 WebDAV 在多台电脑之间同步会话数据。

---

## 1. 核心概念

在使用历史对话功能前，请先理解以下三类数据视图：

### 📂 本地对话 (Local Chats)

* **定义**：存储在当前电脑磁盘中的对话记录。
* **存储机制**：
  1. **自动保存**：当会话开启自动保存后，桌面端会周期性将当前会话保存到本地目录。
  2. **任务生成**：定时任务执行完成后，也可自动生成对应的对话文件。
* **文件格式**：统一使用标准 `.json` 会话文件，包含消息、标题、时间、模型与必要的上下文信息。
* **依赖条件**：需要在「设置 -> 数据管理 / WebDAV」中配置本地对话路径。

### ☁️ 云端对话 (Cloud Chats)

* **定义**：存储在配置的 WebDAV 服务器上的会话备份。
* **用途**：用于跨设备同步。例如，在办公室电脑保存的桌面端对话，可在家中电脑下载后继续处理。
* **依赖条件**：需要在「设置」中正确配置 WebDAV 地址、账号与目录。

### 🗂️ 聊天项目 (Projects)

* **定义**：用于把历史对话按项目 / 主题 / 工作流进行分组管理。
* **存储机制**：项目归属记录在 `projects.yaml` 中，不改变原始 `.json` 会话文件内容。
* **同步机制**：本地与云端都支持项目归属记录；同步会话时，也可以同步项目分组关系。
* **未分组**：未加入任何项目的对话会显示在“未分组”区域，便于后续整理。


### 👌 恢复对话 (Resume Chats)

* **定义**：将已保存的 JSON 对话重新载入到桌面端独立窗口继续聊天。
* **用途**：用于继续先前会话、查看定时任务历史执行过程，或打开其他设备导出的会话文件。
* **依赖条件**：无。

## 2. 界面与操作指南

### 2.1 视图切换

在主控台的“历史对话”页面，可以在 **本地对话** 与 **云端对话** 之间切换。

* 若未配置 WebDAV，云端视图将不可用。
* 若未配置本地对话目录，本地视图将为空，并提示用户先完成路径配置。

### 2.2 数据同步

Anywhere Desktop 提供了面向本地 / 云端的双向同步能力：

* **📤 上传变更**：当本地会话比云端更新，或本地新增了会话文件时，可批量上传到 WebDAV。
* **📥 下载变更**：当云端存在新文件，或云端版本更新时，可批量拉取到本地。
* **单文件强制同步**：在文件列表中可按单项执行同步，用当前版本覆盖另一端。
* **项目归属同步**：同步聊天时，也会尽量合并本地 / 云端 `projects.yaml` 中的项目归属，确保另一台设备打开后仍能看到相同分组。

### 2.3 项目分组与拖拽归档

在历史对话页面中，可以使用“项目”来整理大量会话：

* **创建项目**：新建一个项目分组，用于收纳相关对话。
* **重命名项目**：调整项目名称，便于后续检索。
* **删除项目**：删除项目时可选择：
  * 连同项目内聊天一起删除；
  * 保留聊天，并移动回“未分组”；
  * 取消删除。
* **拖拽归档**：将单个聊天拖入项目，或拖回“未分组”。
* **批量拖拽**：勾选多个聊天后，可批量拖入同一个项目。
* **拖拽自动滚动**：拖拽过程中列表会在靠近边缘时自动滚动，方便把聊天移动到当前不可见的项目。
* **折叠项目**：项目可折叠 / 展开，适合管理大量历史记录。

> 项目用于组织历史对话，不等同于文件夹移动。会话文件仍是标准 `.json`，项目归属由 `projects.yaml` 维护。


### 2.4 文件管理

* **进入对话**：点击 **聊天 / 恢复** 按钮，可立即在桌面端独立窗口中打开该历史会话。
* **重命名**：支持对本地或云端会话文件重命名；重命名时也可重新选择所属项目。
* **删除**：支持删除单个会话，并可按提示决定是否同步删除另一端副本。
* **批量操作**：支持勾选多个历史文件后统一删除。

### 2.5 自动清理

当历史记录过多时，可以使用右上角的清理能力：

1. 选择保留时间范围（如最近 3 天、7 天、30 天或自定义天数）。
2. 预览待删除文件数量与空间占用。
3. 确认后批量清理当前视图中的过期历史文件。

> 注意：自动清理默认只作用于当前视图，不会无提示地联动删除另一端数据。

## 3. 对话的保存与导出

在桌面端独立对话窗口中，可以通过以下方式生成或导出历史记录：

1. **自动保存**：
   * **普通会话**：开启自动保存后，会话会周期性落盘到本地目录。
   * **定时任务**：开启任务自动保存后，执行完成时会自动生成会话文件。
2. **手动保存 / 另存为**：
   * 可通过窗口内保存入口，或使用快捷键 `Ctrl + S`。
   * **保存为 JSON**：用于在 Anywhere Desktop 中恢复并继续聊天。
   * **保存为 Markdown**：适合阅读、归档或发布到笔记 / 博客。
   * **保存为 HTML**：保留较完整的对话样式、头像与时间信息。
   * **保存到云端**：直接将当前对话上传至 WebDAV。
   * **选择所属项目**：保存为本地 JSON、保存到云端或重命名会话时，可直接选择项目，让新会话自动进入对应分组。

## 4. 常见问题 (FAQ)

**Q1: 为什么我看不到“本地对话”列表？**

> **A:** 请先在「设置」中配置有效的本地对话路径。建议选择一个专门用于保存会话的文件夹，例如 `D:\Anywhere_Chats`。

**Q2: 定时任务生成的对话文件名格式是什么？**

> **A:** 通常为 `任务名称-YYYYMMDD-HHMMSS.json`，例如：`每日早报-20260416-080000.json`。

**Q3: 我在 A 电脑上删除了一个对话，B 电脑上还会存在吗？**

> **A:** 如果只删除了本地文件而没有同步删除云端版本，另一台电脑在同步时仍可能再次拉取该文件。建议在删除时留意同步提示。

**Q4: 自动保存的文件名是如何生成的（非定时任务）？**

> **A:** 系统会根据对话标题、首条内容摘要或时间信息生成默认名称，之后仍可在历史对话页中手动重命名。

**Q5: 导入的 JSON 文件格式有什么要求？**

> **A:** 建议使用 Anywhere Desktop 导出的标准 JSON 会话文件。手工修改 JSON 可能造成字段不兼容或显示异常。

**Q6: 删除项目会不会删除里面的聊天？**

> **A:** 删除项目时会出现选项。可以选择“连同聊天一起删除”，也可以选择“保留聊天并移动到未分组”。如果只是想取消分组，建议选择保留聊天。

**Q7: 项目分组会同步到另一台电脑吗？**

> **A:** 可以。项目归属会记录在本地或云端的 `projects.yaml` 中。执行上传、下载或强制同步时，系统会尽量合并会话文件与项目归属。

**Q8: 如果我重装了系统，历史记录会丢失吗？**

> **A:**
>
> * **本地对话**：如果会话目录放在非系统盘、NAS 同步盘或云盘目录中，重装后重新指定目录即可恢复，否则历史记录会丢失。
> * **云端对话**：只要 WebDAV 服务中的数据仍在，重新配置 WebDAV 后即可找回云端历史。
