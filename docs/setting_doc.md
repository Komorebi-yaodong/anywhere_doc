# 设置

**文档更新时间：2026年7月26日**

「设置」页面是 Anywhere Desktop 的全局控制中心。在这里可以对桌面行为、界面外观、全局快捷键、数据备份、WebDAV 同步以及语音功能进行精细配置。

合理的设置可以让桌面端更加贴合用户本机使用习惯。

---

## 1. 通用设置 (General Settings)

* **语言 (Language)**：切换界面语言。
* **主题 (Theme)**：
  * **跟随系统**：跟随 Windows / macOS 的深浅色模式；
  * **浅色 / 深色**：手动固定主题。
* **显示成功通知**：开启后，任务完成、保存成功等事件会给出提示。
* **固定窗口位置**：开启后，独立窗口会记忆位置，而不是每次重新按默认策略出现。

### 全局行为控制

这些设置可作为新建助手的默认值，或用于统一已有助手的行为：

* **全局窗口置顶**
* **全局失焦关闭**
* **全局自动保存对话**

### 输入习惯

* **发送时跳过换行符**：适合处理复制自 PDF / 网页的断行文本。
* **Ctrl+Enter 发送**：
  * 开启：`Enter` 换行，`Ctrl+Enter` 发送；
  * 关闭：`Enter` 发送，`Shift+Enter` 换行。

## 2. 桌面端设置

这是 Anywhere Desktop 相比原插件最关键的一组设置。所有快捷键都在系统级注册；录制时直接按下目标组合键，按 `Esc` 可取消录制。请避免与 Windows、输入法或常用软件快捷键冲突。

### 2.1 主快捷键

可配置以下主控台级快捷键：

* **主界面快捷键**：显示或隐藏 Anywhere 主控台；
* **召唤快捷键**：打开 Quick 快捷召唤面板；
* **自动追问快捷键**：将当前选中的文本、图片或文件追加到目标对话窗口；
* **独立窗口失焦自动关闭快捷键**：快速切换当前独立对话窗口的失焦关闭行为。

### 2.2 快捷助手专属快捷键

可为任意可用的独立窗口快捷助手新增专属快捷键绑定：选择助手、录制组合键并启用开关即可。多个绑定会统一检查冲突；如需停用某个绑定，可关闭该行开关或移除该行。

### 2.3 托盘与关闭行为

* **关闭到托盘**：关闭主窗口时不退出程序，而是隐藏到系统托盘；
* **托盘常驻**：适合需要全局快捷键、定时任务和后台 AI 能力长期运行的场景。

### 2.4 用户资料

桌面端支持设置昵称与头像，它们会显示在独立对话窗口的用户消息中。

* **昵称**：最多 12 个字符，失焦后自动保存；
* **头像**：支持上传、拖拽或粘贴 PNG、JPEG、WebP 图片；
* **头像编辑**：上传后可拖动图片、滚轮缩放，并调整圆角后保存；
* **移除头像**：移除后回退到默认显示。

---

## 3. 语音设置 (Voice Settings)

Anywhere Desktop 支持语音输出，让 AI 可以“说话”。

* **语音列表管理**：添加、编辑、删除语音预设；
* **常见格式**：`voiceId` 或 `voiceId - note`；
* **使用方式**：在快捷助手配置中为特定助手指定默认语音。

---

## 4. 数据管理

数据管理卡片包含本地路径与配置迁移功能：

* **导出配置**：将快捷助手、服务商、MCP、部分 Skill 绑定关系等配置打包为 `.json` 文件；
* **导入配置**：从导出的 `.json` 文件恢复配置；
* **本地 Skill 路径**：选择包含多个 Skill 文件夹的父目录；
* **本地对话路径**：指定自动保存 JSON 对话的目录。

> 注意：配置文件可能包含 API Key、WebDAV 登录信息或自定义 Header。导出、备份或分享前，请确认文件只交给可信对象。

---

## 5. WebDAV 同步与备份

WebDAV 用于跨设备保存配置、历史对话与可选的 Skill 备份。

### 5.1 配置项

* **WebDAV 地址**：如坚果云、Nextcloud、NAS、Koofr 等；
* **用户名 / 密码**：认证信息；
* **配置路径**：存放桌面端配置与备份；
* **数据路径**：存放历史对话文件。

### 5.2 配置与对话备份

* **备份到 WebDAV**：手动备份当前配置；
* **管理备份**：查看并恢复云端配置备份；
* 历史对话的上传、下载与项目分组同步，请参阅《历史对话》。

### 5.3 Skill WebDAV 备份

在 WebDAV 卡片中可以将选中的本地 Skill 打包同步到 `配置路径/skill/`，也可以打开云端备份管理器查看和恢复备份。

* 同步前需先配置有效的 WebDAV 地址、账号和配置路径；
* 单个 Skill 打包文件上限为 50 MB；
* 云端恢复只恢复 Skill 文件，目标电脑的运行环境、依赖和本地路径仍需自行检查；
* 同步进行时可查看进度与失败项，也可取消尚未开始的同步工作。

---

## 6. 设置卡片管理

设置页由通用、桌面端、语音、数据管理和 WebDAV 等卡片组成：

* 可拖动卡片标题调整排列顺序；
* 可展开或收起单张卡片；
* 排序与收起状态会保存在本地配置中，下一次打开仍会保留。

## 7. 常见问题 (FAQ)

**Q1: 为什么修改了“全局窗口置顶”，有些助手没变化？**

> **A:** 某些助手可能已拥有独立配置。再次统一切换全局设置时，桌面端会尝试批量覆盖已有助手配置。

**Q2: WebDAV 连接失败怎么办？**

> **A:**
>
> 1. 检查 URL 是否带协议头；
> 2. 部分服务商需要应用专用密码；
> 3. 检查网络与代理环境是否能访问该服务。

**Q3: 为什么语音没有声音？**

> **A:**
>
> 1. 确认模型支持语音输出；
> 2. 确认语音 ID 正确；
> 3. 检查系统音量与输出设备。

**Q4: 为什么全局快捷键没有生效？**

> **A:**
>
> 1. 检查是否与系统热键冲突；
> 2. 检查应用是否仍在后台运行；
> 3. 修改快捷键后可尝试重启桌面端以重新注册。
